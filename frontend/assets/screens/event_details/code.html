About This Event

Join 50 senior product designers, UI engineers, and design system leads for an intensive six-hour, deep-dive architectural workshop in San Francisco. Transition from static component libraries to bulletproof, token-driven multi-platform design ecosystems that scale cleanly across iOS, Android, and web frontends.

Through real-time collaborative Figma labs and paired architectural challenges, Elena Rostova will guide you through orchestrating multi-brand variables, writing composable documentation, establishing design governance councils, and bridging the code handover friction with zero token drift.

What You Will Master

schema

Design Tokens 2.0

Semantic variable structures, light/dark aliases, and cross-platform JSON transforms using Style Dictionary.

token

Composable Slots

Architecting complex organisms without nesting hell; leveraging Figma component properties and variants seamlessly.

handshake

Federated Governance

Protocols for review councils, deprecation cycles, and avoiding system fragmentation across distributed squads.

code_blocks

React & Tailwind Parity

Ensuring 100% 1-to-1 parity between design canvas component props and production React/TypeScript APIs.

info

Prerequisites & Setup

Bring a laptop with the latest Figma Desktop client installed and an active Figma account. Familiarity with component variants and auto-layout is highly recommended.

Workshop Agenda

10:30 AM – 11:45 AM Stage A • Keynote

Foundational Design Systems & Token Architecture

The current state of modern multi-brand systems, breaking down token schemas from primitive values to contextual semantics.

12:00 PM – 1:30 PM Hands-on Lab

Figma Systems Lab: Advanced Variables & Responsive Modes

Live exercises configuring color modes, localized dimensions, and typography scaling across viewport containers.

2:30 PM – 3:45 PM Architecture Studio

Real-World Component Architecture & Code Handover

Bridging Figma variables with Tailwind theme plugins, Git PR workflows, and automated token regression testing.

4:00 PM – 4:30 PM Design Lounge

Executive Q&A, Portfolio Reviews & Networking Mixer

Relaxed discussion on design careers, team leadership, craft questions, accompanied by craft coffee and refreshments.
